aprueba sin hallazgos; backend, frontend, tests, código y paridad piden cambios. Ninguna

(M1a … M1d): no abre ninguna fuga, pero cambia la respuesta que fija §4.4. El hydration
mismatch de `AppLayout` no lo trae el slice: es el `MetadataWrapper` de Next durante una
recarga en caliente con el árbol sin commitear, y no se reproduce. Queda cerrado.
