# Especificaciones de paridad

Un archivo por módulo, `docs/parity/<modulo>.md`, escrito por `parity-analyst`
antes de diseñar o implementar. Es la referencia de `parity-reviewer` y de los
flujos de Playwright.

Cada comportamiento se marca como `replicar`, `adaptar` o `fuera de alcance`.

El workspace del equipo está en el plan Free de Clockify: las tarifas, las
aprobaciones, el bloqueo de timesheets y los campos obligatorios no se pueden
relevar porque no existen en ese plan. La fase 4 no tiene especificación de
paridad: su alcance lo define el equipo y lo escribe `architect`.
